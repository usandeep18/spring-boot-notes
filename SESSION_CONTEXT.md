## Learner Profile
- Knows Java already. Zero Spring/Spring Boot knowledge.
- Goal: go from zero to **3 YOE (Years of Experience) professional Java/Spring Boot developer** level, ready to crack interviews.
- Focus: **industrial/interview-prep level**, NOT academic/research-focused.
- Explanations must be **simple and easy to understand**, no unnecessary complexity.

## Course Requirements
1. Teach chapter by chapter, from absolute scratch to advanced — no topic skipped.
2. Each chapter must include: detailed explanation, flow diagrams, and code snippet examples.
3. Include **source code references** in notes so the learner can check/execute the actual runnable code.
4. Provide easy → difficult practice questions after each chapter.
5. Each chapter's exercise file must also include the actual questions the learner asked during that chapter.
6. If the learner gets stuck or raises a doubt mid-chapter, add it into that chapter's notes file, **highlighted**, with a proper answer — don't just answer in chat and drop it.
7. Review the learner's existing project code (in `myProject2`) like a teacher — point out gaps/mistakes — and fold this into relevant chapters.
8. Learner will use a **different/new chat per chapter** — so this file must always be current enough to resume from cold.
9. **Hands-on rule**: after teaching a chapter's theory, the learner implements it themselves in `myProject2` BEFORE moving to that chapter's exercises. Exercises are not the first hands-on contact with the topic.
10. Skip/de-prioritize topics with low current industry relevance — cover them last (see Chapter 16 in `ROADMAP.md`), don't skip entirely since some are still interview-asked.
11. Diagrams in notes use **Mermaid** syntax.
12. Do NOT scan/review `myProject2` code upfront — scan and explain the relevant part of it only when it becomes relevant within a chapter, at that chapter's level.
